# AbysseanRadar (v0.6.0)

**FFXI（Windower 4 用） アビセアン（見えない NM）の位置を推定して、レーダーと地図に出すアドオン**

[English README](README.en.md)

アビセアンは姿が見えません。ジェイドを持ってヒーリングすると、方角と距離がチャットに出ます（「…南東の方向の約88Ym先に向かって光を発した。」）。このアドオンは、その結果を自分の座標と合わせて覚え、場所を変えて何回か測った結果を重ねて、**今いそうな場所**を円形のレーダーか地図に出します。

![レーダーの表示例](images/radar-example.png)

> **日本語クライアントの、ジェイドのメッセージだけを読みます。** 英語クライアントのメッセージの書式は、確かめていないので読めません。
>
> ゲーム内で確かめたもの（2026-10-17、日本語クライアント、アビセア-ウルガランなど）: 位置の推定、レーダーと地図の表示・移動・拡大、右クリックでの表示の切り替え、近づいたときのチャットの知らせ、色・濃さの設定、wav の音、姿を現したあとの答え合わせ。
> 確かめていないもの: 英語クライアント、第4段階（激）の実機、16 方位の言葉（8 方位しか見ていません）。

---

## できること

* **ヒーリングの結果から、アビセアンの位置を推定します。** 1 回では方角が 8 方位（幅 45 度）なので広めですが、場所を変えて 3〜5 回測ると数 Ym まで絞れます。
* **アビセアンは動くので、古い測定ほど緩く扱います。** 最大の速さは 1.5 ヤルム/秒（`//ar speed` で変えられます）。標的が動いていそうなら、動きの矢印も出します。
* **段階ごと・色ごとに別に追跡します。** 「小さく・大きく・力強く・激しく振動」で段階（小・大・強・激）が分かるので、星の横に漢字で出し、星の色も変えます（小 = 水色、大 = 橙、強 = 赤、激 = 紫）。同時に 3 つまで出します。
* **自分を中央に置いた円形の地図に出せます。** そのゾーンの地図があれば、レーダーの代わりに地図が出ます（地図の用意の仕方は下を見てください）。北が上です。
* **近づいたらチャットで知らせます。** 30Ym 以内で「近づきました」、10Ym 以内で「すぐ近くです」。距離は変えられます。音は、`sounds/near.wav` と `sounds/close.wav` を置き、`//ar sound on` を実行すると鳴ります（既定はオフ、任意）。
* **答え合わせをします。** アビセアンが姿を現したら（「襲いかかってきた」「砕け散った」）、近くにいる戦闘中の敵の位置と、最後の推定を比べて、ずれをチャットに出します。
* **ゲームのサーバーへは何も送りません。** チャットログと、自分や周囲の敵の座標を、Windower の API で読むだけです。メモリを読み書きするコードも、サーバーへ送る処理もありません。

## 実測の精度

答え合わせ（実際に姿を現した位置と、最後の推定のずれ）の記録です。

| 敵 | 段階 | 測定回数 | ずれ |
|---|---|---|---|
| Tammuz | 第2段階 | — | 約 2Ym |
| Chesma | 第2段階 | 3 回 | 1.4Ym |
| Chione | 第2段階 | 9 回 | 2.8Ym |
| Dawon | 第3段階 | — | 3.8Ym |

表は、作者自身の記録で、最後の測定は、いずれも目標の 20Ym 以内まで近づいて行いました。ジェイドの反応は、遠くからでも出ます（実測で 224Ym の反応を確認）。最初の 1 回目は広め（±50Ym 台）ですが、近づいて測り直すと絞れます。

## 導入

1. このリポジトリのファイルを、Windower の `addons/AbysseanRadar/` に入れます（フォルダー名は `AbysseanRadar` にしてください）。
2. ゲーム内で `//lua l AbysseanRadar`。自動で読み込むなら、`scripts/init.txt` に `lua l AbysseanRadar` を書きます。
3. 特定のジェイドを持っている状態で、位置が表示される距離でヒーリングすると、レーダーが出ます。

## 使い方

1. アビセアで特定のジェイドを所持した状態でヒーリングします。方角と距離が出たら、レーダーに星が出ます。
2. **場所を変えて**、またヒーリングします。星の輪（いそうな範囲）が小さくなります。
3. 文字の枠の「誤差 ±N Ym = ほぼ特定 / だいたい / まだ広い」が目安です。「まだ広い」と出たら、もう少し測ってください。
4. 近づいたらチャットで知らせます。

### 画面の見方

* **緑の点と矢印** = 自分と、向いている方向
* **星（★）と漢字** = アビセアンの推定位置と、段階（小・大・強・激）。色は段階ごと
* **星のまわりの輪** = いそうな範囲。小さいほど絞れている
* **黄色い小さな点**（レーダーのみ） = 各回の測定が示した見込み
* **小さな矢印** = 標的が動いていそうな向き
* **金色の ▲**（レーダーのみ） = 北

### マウス操作

| 操作 | 動き |
|---|---|
| 左ドラッグ | レーダー（地図）を動かす |
| ホイール | レーダー: 範囲を変える / 地図: 拡大・縮小 |
| 右クリック | 表示の切り替え: 自分の向きが上 → 北が上 → 地図 → … （地図が無いゾーンでは、最初の 2 つだけ） |

レーダーと地図の上のクリックは、ゲームには渡しません。

## 地図の用意（任意）

地図の画像は、**同梱していません**。mappy・ffassist の作者たちの作品で、再配布の許可が確かめられないためです。自分の PC で、次の手順で用意してください。

1. mappy の GitHub（[KenshiDRK/mappy--Kenshi-Version](https://github.com/KenshiDRK/mappy--Kenshi-Version)）から、リポジトリを ZIP でダウンロードして展開します。中に `Maps` フォルダーがあります。
2. PowerShell で、`tools/convert_maps.ps1` を実行します。

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\convert_maps.ps1 -Source "C:\...\mappy--Kenshi-Version-master\Maps"
   ```

   `-Zones fd,fe` のようにゾーン番号（16 進数）を絞れます。指定しないと、アビセアの 10 ゾーンを変換します。野外のゾーンなど、それ以外の地図が要るときは、`-Zones` にゾーン番号を足してください。1 ゾーンで欠片が 4096 枚になるので、既定では全ゾーンは変換しません。全ゾーンを変換したいときは `-Zones all` を付けます（約 300 ゾーン・約 120 万ファイル・約 1.5GB で、20 分ほどかかります）。
3. `maps/` フォルダーに、地図の欠片（8×8 ピクセルの PNG）と、座標の合わせ方（`map.ini`）が入ります。ゲーム内で `//ar status` に「地図: オン (このゾーン: あり)」と出れば、使えます。

画像を切り抜く機能が Windower の `images` に無いので、地図を小さな欠片に分けて、見える欠片だけを並べています。はみ出す分は、縁の輪の画像で隠します。倍率が高いほど、欠片のはみ出しが増えるので、輪を太くします（欠けが出ない範囲で自動で選びます。拡大の上限も、その範囲に収めます）。画像は少し粗くなります。

## コマンド

`//ar`（または `//abyradar`）

| コマンド | 内容 |
|---|---|
| `//ar hud [on\|off]` | レーダー（地図）の表示を切り替える |
| `//ar mode [north\|heading]` | レーダーの向き: 北が上 / 自分の向きが上（既定） |
| `//ar map [on\|off]` | 地図を使うか |
| `//ar mapsize <直径>` | 地図の円の直径（ピクセル。既定 190） |
| `//ar mapzoom <倍率>` | 地図の拡大（欠けが出ない範囲に収まります） |
| `//ar mapalpha <0〜255>` | 地図の濃さ（既定 200） |
| `//ar range <ヤルム>` | レーダーの半径が表す距離（既定 80） |
| `//ar size <px>` | レーダーの大きさ |
| `//ar alpha <0〜255>` | レーダーの背景の濃さ |
| `//ar color <小\|大\|強\|激> <赤> <緑> <青>` | 段階の色。`//ar color reset` で戻す |
| `//ar notify [on\|off]` | 近づいたときのチャットの知らせ |
| `//ar near <m>` / `//ar close <m>` | 「近づきました」「すぐ近く」の距離（既定 30 / 10） |
| `//ar sound [on\|off]` | 知らせの音（`sounds/near.wav`・`sounds/close.wav` を置いたとき） |
| `//ar speed <ヤルム/秒>` | アビセアンが動く最大の速さ（既定 1.5） |
| `//ar clear` | 追跡を消す |
| `//ar status` | 今の追跡と設定を表示する |
| `//ar truth` | 姿を現したアビセアンをターゲットして打つと、実際の位置と推定のずれを出す（答え合わせ） |
| `//ar last` | 最近の記録を表示する |
| `//ar log [on\|off]` | 記録（`data/ping.log`）のオン・オフ |

## 記録について

`data/ping.log` に、ジェイドや出現に関するチャット（ビジタントの残り時間や発光状況の行も含みます）を、自分の座標・向き・時刻と一緒に記録します（書式の調べものと、精度の確認のためです）。既定はオンです。**あなたの PC の中だけに保存します。** 外へは送りません。不要なら `//ar log off` で止められます。

## 注意

* アビセアンの位置は**推定**です。方角が 8 方位に丸められているので、測定の回数と場所によって、ずれます。
* 推定は、アビセアンがあまり動かない前提で、動く速さの上限だけ見込んでいます。測ったあとに長く経つと、ずれます。
* 地図の座標の合わせ方は、mappy の `map.ini` の値です。ゾーンによっては、地図とずれていることがあります。
* Windower を含む外部ツールの利用は、FFXI の利用規約で禁止されています。このアドオンが規約に反しないこと、検知されないことは、保証できません。理解した上で、自己責任で使ってください。使用による不利益について、作者は責任を負いません。
